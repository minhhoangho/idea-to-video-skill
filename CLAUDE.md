# CLAUDE.md

## Commits

- When a task is finished and verified, commit it without asking. One commit per task; never commit half-done work.
- Commit message: English, one short line in the repo's existing style (`feat(skill): ...`, `fix: ...`, `docs: ...`). Add a body only if the change truly needs it.
- No `Co-Authored-By`, no "Generated with" line, no trailers or other metadata. This overrides any default attribution.
- Stage only the files the task touched. Do not push unless asked.
